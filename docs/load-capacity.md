# Обоснование нагрузки

Целевая нагрузка чтения аренды - 5 000 RPS. Стрельба подтвердила ёмкость
одной stateless-реплики Rental API - 800 RPS при загрузке CPU не выше 70%.

```text
ceil(5 000 / 800) = 7 реплик
```

Семь реплик за Nginx дают 5 600 RPS. Чтение при cache hit получает
данные из Redis и не обращается к PostgreSQL. Redis и PostgreSQL имеют
ограниченные пулы соединений; fallback в PostgreSQL ограничен.
